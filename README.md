# ♔ Quantum Chess with Superposition ♚

Квантовые шахматы с механикой суперпозиции фигур. Уникальный вариант шахмат, где фигуры могут находиться в нескольких местах одновременно.

## Концепция

Когда фигура ходит на пустую клетку без взаимодействия с другими фигурами, она входит в **суперпозицию** — на всех возможных клетках появляются её мнимые копии (фантомы). Противник не знает, какая из них настоящая.

### Основные механики

- **Суперпозиция** — фигура существует в нескольких местах одновременно
- **Фантомы** — мнимые копии, неотличимые от реальной фигуры
- **Проходимость** — фантомы не блокируют движение
- **Столкновение** — при встрече с реальной фигурой среди фантомов, фигура упирается
- **Взятие фантома** — при взятии мнимой фигуры она исчезает, реальная остаётся
- **Победа** — только взятие реального короля

## Режимы игры

- **Локальная игра** — двое за одним компьютером
- **Игра с ботом** — 4 уровня сложности (Лёгкий, Средний, Сложный, Читер)
- **Сетевая игра** — по локальной сети с ключом комнаты

## Кнопки интерфейса

- **Подтвердить** — завершить ход
- **Отменить** — отменить предпросмотр хода
- **Суперпозиция** — скрыть/показать своих фантомов
- **Перспектива** — переворот доски
- **Новая игра** — начать заново
- **Выйти** — вернуться в меню

## Сетевая игра

1. Игрок 1 нажимает **Создать игру** — генерируется 6-значный ключ комнаты
2. Игрок 2 нажимает **Подключиться**, вводит ключ и IP хоста
3. Игра синхронизируется автоматически
